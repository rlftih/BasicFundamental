1. **Algoritma** : Urutan langkah-langkah logis untuk menyelesaikan suatu masalah.

2. **Bahasa Pemrograman** : Bahasa yang digunakan untuk menulis instruksi agar dijalankan komputer.

3. **Tipe Data** : Menentukan jenis nilai yang dapat disimpan, seperti `int`, `float`, atau `string`.

4. **Variabel** : Tempat menyimpan data yang nilainya dapat berubah selama program berjalan.

5. **Konstanta** : Tempat menyimpan data yang nilainya tetap dan tidak dapat diubah.

6. **Percabangan** : Struktur yang digunakan untuk memilih aksi berdasarkan suatu kondisi.

7. **Perulangan** : Struktur yang digunakan untuk menjalankan perintah secara berulang.

8. **Package** : Kumpulan class atau modul yang disusun dalam satu kelompok untuk memudahkan pengelolaan.

9. **Error Handling** : Teknik menangani kesalahan agar program tidak berhenti secara tiba-tiba.

10. **Debugging** : Proses mencari dan memperbaiki kesalahan (bug) pada program.

11. **Enkapsulasi (Encapsulation)** : Konsep OOP untuk melindungi data dengan membatasi akses langsung.

12. **Inheritance** : Konsep OOP yang memungkinkan class mewarisi sifat dan metode dari class lain.

13. **Polimorfisme (Polymorphism)** : Konsep OOP yang memungkinkan satu metode memiliki banyak bentuk perilaku.

14. **Interface** : Kontrak yang berisi metode yang harus diimplementasikan oleh class.
